Hello from Apache NuttX!

This page is being served by Apache NuttX RTOS running on a real Sony Spresense board, reached over a real WireGuard tunnel — not a simulator, not a VM.

BoardSony Spresense main board + iS110B Wi-Fi add-on (v1.0C)
SoC / CPUSony CXD5602, ARM Cortex-M4F
Wi-FiGS2200M module over SPI, usrsock daemon (TCP/IP offloaded to the module)
Tunnelwg0 = 10.11.0.2, Windows tunnel nuttx-spresense (UDP 51821)
OSApache NuttX 12.7.0, FLAT build

WireGuard is ported to NuttX as a native wg0 network interface: an RTOS device speaking the real protocol to the official Windows client on the other end. This board's Wi-Fi driver is a usrsock proxy rather than a kernel netdev, so the same wg0 code is running on two quite different network back-ends.

telnet in, run webserver &, and load this page from a browser on the other end of the tunnel.
