Hello from Apache NuttX!

This page is being served by Apache NuttX RTOS running on a real Sony Spresense board (ARM Cortex-M4F, Wi-Fi via a GS2200M add-on), reached over a real WireGuard tunnel (wg0, 10.10.0.2) — not a simulator, not a VM.

WireGuard is ported to NuttX as a native wg0 network interface: an RTOS device speaking the real protocol to the official Windows client on the other end.

telnet in, run webserver &, and load this page from a browser on the other end of the tunnel.
